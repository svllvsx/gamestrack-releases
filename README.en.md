<h1 align="center">GamesTrack Releases</h1>

Public downloads for a game release tracker with discovery, personal lists, calendars and reminders.

This is a public project showcase. Source code, current releases and setup instructions are available in the [original repository](https://github.com/svllvsxprod/gamestrack-releases). The complete original README is mirrored [here](README.md).
