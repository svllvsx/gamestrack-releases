<h1 align="center">GamesTrack Releases</h1>

Публичные сборки трекера игровых релизов с подбором, личными списками, календарём и напоминаниями.

Это публичная витрина проекта. Исходники, актуальные сборки и инструкции находятся в [оригинальном репозитории](https://github.com/svllvsxprod/gamestrack-releases). Полная копия исходного README сохранена [здесь](README.md).

**Темы:** `games`, `release-tracker`, `calendar`, `mobile-app`, `releases`
