<h1 align="center">GamesTrack</h1>

GamesTrack — каталог игровых релизов, личные коллекции, календарь и напоминания для Android и веба.

Это публичная витрина проекта. Публичные сборки, скриншоты и инструкции находятся в [оригинальном репозитории](https://github.com/svllvsxprod/gamestrack-releases). Полная копия исходного README сохранена [здесь](README.md).

**Темы:** `games`, `release-tracker`, `calendar`, `mobile-app`, `releases`
